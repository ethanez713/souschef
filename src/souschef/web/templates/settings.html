SousChef only ever stores the session cookie, never your password — NYT blocks automated logins, and a stored password would be far more damaging if this server were ever compromised. The cookie is encrypted with a key held outside the database. It expires periodically; paste a fresh one when imports start failing.

To find it: sign in to NYT Cooking in your browser, open DevTools → Application → Cookies → nytimes.com, and copy the NYT-S value.
